Segurança dos dados

Pasta de dados no computador

Escolha uma pasta deste computador (de preferência dentro do OneDrive). Os controles gravam sozinhos uma cópia de tudo nela, a cada minuto e quando você troca de janela. Se o navegador for limpo ou você abrir uma versão nova do app, é só escolher a mesma pasta de novo e carregar os dados. A pasta guarda também uma cópia por dia dos últimos 30 dias (subpasta copias). Funciona no Google Chrome e no Microsoft Edge.
